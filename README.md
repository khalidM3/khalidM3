## Selected work

### [Overgent](https://github.com/khalidM3/overgent)

Open-source air traffic control for coding agents. Overgent combines local
observation, deterministic conflict detection, optional semantic judgment, and
targeted context routing without taking over the coding agent's model loop or
editing its work.

The project includes:

- A Go CLI and per-user local service
- React and TypeScript desktop and web interfaces
- Versioned HTTP, OpenAPI, and JSON Schema contracts
- Cross-platform installers and signed release metadata
- CI, CodeQL, Dependabot, SBOMs, and documented security/privacy boundaries
